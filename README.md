# tuckaboo-site

Public pages for the **Tuckaboo** iOS app — calm bedtime stories and learning games, made for your child.

These are the URLs App Store Connect requires, served by GitHub Pages from `main` + `/docs`:

| Page | URL |
|---|---|
| Home | https://siysinyuy.github.io/tuckaboo-site/ |
| Privacy policy | https://siysinyuy.github.io/tuckaboo-site/privacy/ |
| Terms of use | https://siysinyuy.github.io/tuckaboo-site/terms/ |
| Support | https://siysinyuy.github.io/tuckaboo-site/support/ |

## Editing

The pages are generated in the (private) app repo from `AppStore/site/site.json` by
`AppStore/site/build_site.py`. Edit the source there, re-run the builder, then copy the
`docs/` folder across and push here — edits made in the app repo do not reach these
pages on their own.
